# Журнал ZCraft

Хронология решений и состояния проекта. Дополняется в конце каждой сессии — одна-две строки,
чтобы следующая сессия (или следующая жизнь) входила в курс без чтения переписки.

Правило: если решение меняет архитектуру, формат данных или рабочий процесс — оно попадает сюда,
а не остаётся в чате.

## 2026-11-09

- Починены права Windows на папку проекта: DSH не мог запускать команды. Резервная копия и откат
  в `.dsh-acl-recovery/` (в `.gitignore`).
- Проверено: `dotnet build ZCraft.csproj` — 0 ошибок; `dotnet run --project Tests/NetworkTransport` —
  все проверки транспорта проходят.
- Созданы `AGENTS.md` (карта проекта) и `TODO.md` (состояние и вертикальный срез).
- Оплата: официальная платформа принимает только зарубежные карты; российские отклоняются по BIN.
  Альтернативы — виртуальная карта, посредник, крипта, реселлер API. У DeepSeek нет пакетов токенов
  и нет подписки: только пополнение баланса в долларах.
- Аудит расхода: за сессию (58 запросов) 347k вход-без-кэша, 3.16M из кэша, 45k выход ≈ $0.09
  при рабочем кэше. У шлюза `ewoi.tech` префиксный кэш не работает (повторные промахи по 70k),
  это делает его в ~6 раз дороже официального маршрута. Скрипт аудита: `.build/token-audit.js`.

## 2026-11-10

- Решение по «памяти»: память проекта живёт в репозитории (`AGENTS.md`, `TODO.md`, этот журнал),
  а не в переписке. Контекст сессии конечен и сжимается компакцией, файлы — нет.
- План пополнения: держать баланс официальной платформы с запасом на месяц работы, не допускать
